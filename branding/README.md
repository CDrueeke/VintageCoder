# VintageCoder-Logo

Das offizielle Logo besteht aus Pixelblöcken und einem gelben Punkt. Erzeugt wird alles von `tools/gen_logo.py`
(Icon zusätzlich von `tools/gen_icon.py`); die Dateien hier nicht von Hand ändern.

| Datei | Verwendung |
|---|---|
| `vintagecoder-icon.svg/.png` | App-Icon „VC.“ auf violetter Kachel (Releases, Pakete, Fensterpiktogramm) |
| `vintagecoder-wordmark.svg/.png` | Wortmarke „VintageCoder.“ auf violettem Grund (Website, README, Präsentationen) |
| `vintagecoder-wordmark-light.*` | Wortmarke ohne Grund, helle Blöcke, für **dunkle** Flächen |
| `vintagecoder-wordmark-dark.*` | Wortmarke ohne Grund, dunkle Blöcke, für **helle** Flächen |
| `vintagecoder-mark-light.*` / `-dark.*` | „VC.“ ohne Grund, wie oben |

Schreibweise: **VintageCoder** (Groß-/Kleinschreibung, ein Wort). Der gelbe Punkt gehört zum Logo.
