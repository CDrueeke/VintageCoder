# Verhaltenskodex

Wir wollen, dass VintageCoder ein freundlicher Ort für alle ist, die sich für Retro-Rechner interessieren, egal wie viel Erfahrung sie mitbringen.

- Sei respektvoll und sachlich. Kritik gilt der Sache, nicht der Person.
- Keine Beleidigungen, Belästigung, Diskriminierung oder persönlichen Angriffe, auch nicht in Issues, Pull Requests oder E-Mails.
- Veröffentliche keine privaten Daten anderer.
- Hilf Anfängern; „Das steht im Handbuch“ ist besser mit einem Link gesagt.

Beiträge, die dagegen verstoßen, können ohne Vorwarnung entfernt werden, und wer wiederholt dagegen verstößt, wird von der Mitarbeit ausgeschlossen. Entscheidungen trifft der Projektinhaber. Meldungen bitte per E-Mail an **vintagecoder@drueeke.de**; sie werden vertraulich behandelt.
