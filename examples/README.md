# Beispielprojekte / Example projects

**Deutsch:** Jeder Ordner `examples/<system>/<projekt>/` ist ein Beispielprojekt (Quelltexte und Kommentare deutsch). Der Ordner `examples/en/` spiegelt die Projekte auf Englisch: Er enthält nur die Dateien mit englischem Text (Kommentare, Bildschirmtexte der Einstiegsbeispiele, Projekttitel und -beschreibung in der `.vcprj`, README) unter demselben Pfad. Wird ein Beispiel in englischer Sprache geöffnet oder kopiert, werden diese Dateien über das deutsche Projekt gelegt. Die großen Spiele (`prallball`, `troxx`) bleiben im Programm byte-gleich; bei ihnen sind nur Titel, README und der Kopfkommentar der Hauptdatei zweisprachig (der englische Kopfblock steht in der Hauptdatei unter dem deutschen). Prüfung: `python3 tools/examples_en.py pruefen` und `bauen`.

**English:** Each folder `examples/<system>/<project>/` is an example project (source code and comments in German). The folder `examples/en/` mirrors the projects in English: it contains only the files with English text (comments, on-screen texts of the beginner examples, project title and description in the `.vcprj`, README) under the same path. When an example is opened or copied in English, these files are laid over the German project. The large games (`prallball`, `troxx`) stay byte-identical; for them only the title, the README and the header comment of the main file are bilingual (the English header block follows the German one in the main file). Check with `python3 tools/examples_en.py pruefen` and `bauen`.

## Bekannte offene Punkte / Known open points
* Die Bildschirmtexte der `jumprun`-Beispiele (Statuszeile, Titelhinweis, Levelnamen) sind als Zeichencodes im erzeugten `lib/levels.inc` kodiert (Generatoren `tools/gen_jumprun_*.py`) und bleiben vorerst deutsch. / The on-screen texts of the `jumprun` examples (status line, title notice, level names) are encoded as character codes in the generated `lib/levels.inc` (generators `tools/gen_jumprun_*.py`) and stay German for now.
* `standard_charsets` hat keine Quellen (`"sources": []`) und lässt sich in keiner Sprache bauen; das ist eine Eigenschaft des Originals. / `standard_charsets` has no sources (`"sources": []`) and cannot be built in either language; this is a property of the original.
* Erzeugte Dateien (`music.inc`, `demo.inc`, `data_*.inc`) sind im Spiegel als Kopie übersetzt; nach dem Neuerzeugen aus dem Generator müssen sie angepasst werden. / Generated files (`music.inc`, `demo.inc`, `data_*.inc`) are translated copies in the mirror; they must be adapted after regenerating from the generator.
