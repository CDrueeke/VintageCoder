# Hugo & Gumbo (Plus/4)

Self-playing jump-and-run demo in assembler: title picture, four levels with autopilot, finale, back to the start.
Same game logic as the C64 and Atari versions (`lib/core.asm`), own hardware layer `hal_plus4.asm`:

- TED multicolor text with its own character set (256 characters in RAM); multicolor applies per cell via bit 3 of the color RAM value
- Sky bars by raster interrupt (background color `$FF15`)
- **Character sprites**: The TED has no sprites. Hero (3 x 4 cells) and enemy (3 x 3) are computed in every frame from pre-shifted images
  into redefined characters (`$E0`-`$F4`) and blended with the background
- Sound: two TED voices (melody, bass); effects borrow the bass voice

Build: `vcc build .` (target plus4, starts in VICE `xplus4`). The data is generated by `tools/gen_jumprun_plus4.py`.
The operating system is switched off (ROM off), the interrupt vector lies in RAM.
