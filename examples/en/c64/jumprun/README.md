# Hugo & Gumbo (C64)

Self-playing jump-and-run demo in assembler: title picture, four scenes (meadow, cave, castle, clouds), finale, then back to the start.
The hero (multicolor sprite + hires overlay) jumps in sine curves, the enemy climbs ladders and never jumps. SID music and sound effects.

- Build: `vcc build .` or F7 in the IDE; start: `build/jumprun.prg` (e.g. in VICE `x64sc`).
- Assets: `graphics/*` (character set, tile set `hg.vctiles`, screen bank `levels.vcscreen` with the four scenes, title picture, sprites) and `music/tune.vcsong` open the editors of the IDE.
- The files are generated by `python3 tools/gen_jumprun_c64.py` (in the repository root directory) from the common art data `tools/jumprun_art.py`; likewise `lib/levels.inc` (colours, start values, autopilot paths; the tile properties "solid" and "ladder" are in the tile set and come from the export `hg_props`).
- Source: `jumprun.asm` (flow), `hal_c64.asm` (VIC-II, SID, interrupt), `lib/core.asm` (game logic, platform neutral).
