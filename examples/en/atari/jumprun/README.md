# Hugo & Gumbo (Atari 8 Bit)

Self-running jump-and-run demo in assembler: title screen, four levels with autopilot, finale, start over.
Same game logic as the C64 version (`lib/core.asm`), own hardware layer `hal_atari.asm`:

- ANTIC mode 4 (four colors) with its own character set, sky bars via display list interrupt
- Hero made of four players (outline, skin, shirt, trousers), enemy made of the missiles (player-missile graphics)
- Music in RMT format (POKEY, channels 1-3), sound effects on channel 4

Build: `vcc build .` (target atari8, start in atari800 or Altirra). The data is generated by `tools/gen_jumprun_atari.py`.
