# Atari: Turbo BASIC XL

Beispiel für Turbo BASIC XL ohne Zeilennummern (`PROC`/`EXEC`, `WHILE`, `REPEAT`, mehrzeiliges `IF`).

**Zum Starten brauchst du eine Turbo-BASIC-XL-Diskette.** Turbo BASIC XL gehört nicht zum Lieferumfang von VintageCoder. Besorge dir eine Diskette mit Turbo BASIC XL aus einer Quelle, die du nutzen darfst, und wähle sie hier.

1. Projekt öffnen und **F5** drücken. Es erscheint das Banner „Diskette fehlt“.
2. **Bereitstellen …** wählen und deine Diskette (am besten eine Kopie, `.atr`) auswählen.
3. **F5** drücken: VintageCoder baut `build/balken.atr` mit dem Programm als `AUTORUN.BAS` und startet sie im Emulator (atari800).

Die Kopie liegt danach in `turbo/` und steht in der `.gitignore`. Mehr: Hilfeseite „Turbo BASIC XL: Diskette“.

# Atari: Turbo BASIC XL (English)

Example for Turbo BASIC XL without line numbers (`PROC`/`EXEC`, `WHILE`, `REPEAT`, multi-line `IF`).

**To run it you need a Turbo BASIC XL disk.** Turbo BASIC XL is not part of VintageCoder. Obtain a disk with Turbo BASIC XL from a source you are allowed to use, and select it here.

1. Open the project and press **F5**. The banner "Disk missing" appears.
2. Choose **Provide ...** and select your disk (best a copy, `.atr`).
3. Press **F5**: VintageCoder builds `build/balken.atr` with the program as `AUTORUN.BAS` and starts it in the emulator (atari800).

The copy is then in `turbo/` and listed in the `.gitignore`. More: help page "Turbo BASIC XL: disk".
