# Markdown files and preview

VintageCoder shows files with the extension `.md` as a **preview**: headings, paragraphs, lists, tables, code, quotes and links. One command switches between **Preview** and **Source** ("Markdown: Switch between preview and source" in the command palette, Cmd/Ctrl+K).

- The preview is for reading; only the task check boxes can be ticked. Links are colored and underlined and open **only when you click them**: web addresses in the browser of the system (a message names the address), files of the project in the editor (with a line number, at that line), anchors jump to the heading. Blocked links appear struck through.
- Images from the project appear in the preview. If an image is missing or too large, a placeholder appears instead ("Image not found or too large").
- Large documents (for example the license notices in the About dialog) appear in blocks; **Show more blocks** loads more.
- Notes (**Cmd/Ctrl+Shift+T**) are Markdown files in the `notes/` folder of the project.

Writing aids (bold, italic, code, link, lists, tasks, quote, tables) are under **Edit > Markdown > ...**; shortcuts: Cmd/Ctrl+I italic, Cmd/Ctrl+E code, Cmd/Ctrl+Shift+X strikethrough, Cmd/Ctrl+Shift+K link. See also [Editor](help:editor).
