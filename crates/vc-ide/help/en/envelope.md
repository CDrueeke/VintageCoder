# Envelope (instrument)

On the right in the [Tracker](help:tracker) you see the instrument chosen in the list **Instruments**. The name field above it renames it.

## SID
**Waveform** (triangle, saw, pulse, noise), **Pulse width** (only for pulse) and the four controls **Attack**, **Decay**, **Sustain** and **Release**, each 0 to 15.

## POKEY
**Distortion** (Pure tone, Bass, Buzz, Gritty) and the **Envelope per frame**: 16 vertical sliders, one value per frame (0 to 15). The field **Envelope repeats from frame** sets the repeat point.

## PLAY (MEGA65)
The envelopes 0 to 9 have the same controls as on the SID.

To listen first, click a key of the **Keyboard**: it plays the note with the chosen instrument. Changes are part of the song and are saved with it.
