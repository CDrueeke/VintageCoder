# Number tools

The **number tools** (menu **Edit ▸ Numbers and BASIC ▸ Number tools ...** or command palette; there is no shortcut) calculate and convert numbers:

- **Number or expression:** Enter `$D020`, `0xFF`, `%1010`, `255`, `$D000+$20` or `1<<5`. The tool shows the result as **Decimal**, **Hexadecimal** and **Binary**, as **Lo / hi byte**, as **Character (ASCII)** and **Signed**. You set the **Width** (8 or 16 bit).
- **Bit editor:** You toggle single bits with a click (8 or 16 bit); the result appears at once in all notations.
- **Copy** puts the value on the clipboard, **Insert** puts it into the editor at the cursor. **Close** ends the dialog.

The tool names errors with the position ("Number expected at character 3", "Division by 0"). See also [Assembler: expressions](help:asm-expr) and [BASIC tools](help:basic-tools).
