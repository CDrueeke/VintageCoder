# Path fields and "Choose ..."

Wherever you enter a path, a button sits next to the field that opens the file or folder dialog of your system. The path you pick goes into the field. For the **Projects folder** (Settings > General) and the location of a new project, the button is called **Choose …**; for ROM files it is called **Choose ROM file or zip …**. For the emulator (Settings > Targets and hardware) there is **Search**: the button enters the path that was found automatically.

- You can also **type or paste** the path.
- Paths **inside the project** are saved as relative paths (`graphics/hero.vcsprite`), so the project works on every computer.
- When you save, VintageCoder adds missing **file extensions** that fit the type (for example `.vcsprite`).

See also [Settings](help:settings).
