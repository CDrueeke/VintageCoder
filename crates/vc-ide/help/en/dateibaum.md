# File Tree: Tags and Colors

Every file in the tree has a **tag** of three to four letters after the name. It shows the group of the file and is always there as text, never only as a color.

| Tag | Group |
|---|---|
| ASM | Assembler source |
| BAS | BASIC source |
| TRK, PLAY | Music (tracker, PLAY song) |
| SPR, CHR | Sprites, character sets |
| SCR, MAP, PAL | Screens, tile sets, palettes |
| NOT | Notes (Markdown) |
| (no tag), TXT, BIN | Other files, text, binary data |

More signs in the tree:

- **Disk (user):** The Turbo BASIC XL disk that belongs to you has this tag. The note for it: do not commit it, not everyone may pass it on.
- **Folders** have an arrow to open and close them; VintageCoder remembers the open folders for each project.
- The **chosen file** is highlighted. A dot on the tab in the document area shows unsaved changes.

## Controls
- **Click** opens a file; a disk image (`.d64`, `.d71`, `.d81`, `.atr`) opens in the disk editor.
- **Arrow keys** change the row, Right and Left open and close folders, Enter opens. **F2** renames, **Delete** deletes (to the trash).
- **Right click** (or the menu key) opens the context menu: Open, New file, New note, New folder, Rename, Delete, Copy path, Show in folder; on a free area also Collapse all, Reload and Undo move.
- **Dragging** moves a file or a folder into another folder; the paths in the source files are adjusted.
- The buttons above the tree: Filter files, New file, New folder, Close project.
