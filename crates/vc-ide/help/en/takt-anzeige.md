# Clock in the status bar

The display of clock, video standard, lines per frame and cycles per line in the status bar is not available in this version yet. The status bar shows notes about problems, the cursor position, the language of the file and, during a debug session, the program counter.

You set the **variant** of the target system (for example PAL or NTSC) under **Project** > **Targets**; it determines clock and line count for emulator, preview and timing.
