# Tastenkürzel

| Taste | Wirkung |
|---|---|
| F1 | Hilfe zum Wort unter dem Cursor |
| F5 | Bauen und starten |
| F6 | Debuggen (Bauen, Emulator starten, Arbeitsplatz Debug) |
| F7 | Bauen |
| F8 | Weiter (Debugger) |
| F10 / F11 | Schritt über / Schritt hinein (Debugger) |
| Strg/Cmd+O | Projekt öffnen |
| Strg/Cmd+F / Alt+F / L | Suchen / Ersetzen / Gehe zu Zeile (Quelltext) |
| Strg/Cmd+K | Befehle, Dateien und Studios suchen (auch Strg/Cmd+P) |
| Strg/Cmd+B | Seitenleiste ein-/ausblenden (schmales Fenster: Schublade öffnen/schließen) |
| Strg/Cmd+Umschalt+F | In Projekt suchen (Seitenleiste „Suche“) |
| Strg/Cmd+Alt+B | Inspektor ein-/ausblenden |
| Strg/Cmd+J | Fußpanel ein-/ausblenden |
| Strg/Cmd+Umschalt+Eingabe | Seitenleiste, Inspektor und Fußpanel zeitweise ausblenden bzw. zurückholen |
| Strg/Cmd+\ | Editor teilen bzw. Teilung aufheben |
| Strg/Cmd+W | Aktive Datei schließen |
| Strg/Cmd+Alt+S | Alle speichern |
| Einfachklick / Doppelklick / Strg/Cmd+Klick im Projektbaum | Vorschau / fester Reiter / zweiter Editorbereich |
| Strg/Cmd+S | Speichern (auch in den Grafik- und Song-Editoren) |
| Strg+Leertaste | Vervollständigung öffnen; Pfeile wählen, Enter/Tab übernimmt, Esc schließt |
| Strg/Cmd+Z, Umschalt+Z | Rückgängig / Wiederholen (Quelltext-, Grafik- und Song-Editoren) |
| Klick auf die Zeilennummer | Haltepunkt setzen oder löschen |
| Klick auf ▾/▸ im Seitenstreifen | Bereich falten oder entfalten (Bearbeiten entfaltet alles) |
| Leertaste (Tracker) | Wiedergabe starten und anhalten |
| F9 / F10 (Tracker) | Oktave tiefer / höher |
