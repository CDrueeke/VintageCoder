# Tastenkürzel

Die Liste folgt der Befehlstabelle der Oberfläche: Was hier steht, steht auch im Menü neben dem Befehl, in der Befehlspalette (**Cmd/Strg+K**) und unter Einstellungen ▸ **Tastenkürzel**. Die Kürzel sind fest; Anpassen ist noch nicht möglich.

**Cmd** ist die Befehlstaste des Mac. Unter Windows und Linux nimmst du **Strg**. **Umschalt** ist die Hochstelltaste, **Alt** auf dem Mac die Wahltaste.

## Bauen, Starten, Debuggen
| Taste | Wirkung |
|---|---|
| F7 | Projekt bauen |
| F5 | Startprogramm starten (baut zuerst) |
| F6 | Startprogramm debuggen |
| Alt+Umschalt+F7 | aktive Datei bauen |
| Alt+Umschalt+F5 | aktive Datei starten |
| Alt+Umschalt+F6 | aktive Datei debuggen |
| Alt+F5 | Debuggen: Weiter |
| Alt+F6 | Debuggen: Anhalten |
| F10 | Debuggen: Schritt über |
| Alt+D, Alt+B, Alt+A, Alt+P, Alt+H | Menü Datei, Bearbeiten, Ansicht, Projekt, Hilfe öffnen (nur Windows und Linux, wo die Menüleiste im Fenster steht; auf dem Mac gilt die Menüleiste des Systems, Option+Buchstabe bleibt Text; der unterstrichene Buchstabe im Menünamen; AltGr löst nichts aus) |
| F11 | Debuggen: Schritt hinein |
| Umschalt+F11 | Debuggen: Schritt hinaus |
| Umschalt+F5 | Debuggen beenden |
| F9 | Haltepunkt in der Zeile mit dem Cursor umschalten |
| Alt+F8 | Tests ausführen |
| F8 / Umschalt+F8 | nächstes / voriges Problem |
| Cmd/Strg+Umschalt+E | Exportieren … |

Das Startprogramm legst du in den Projekt-Einstellungen fest. Alle Debug-Befehle stehen im Menü **Projekt**.

## Bearbeiten und Suchen
| Taste | Wirkung |
|---|---|
| Cmd/Strg+Z / Cmd/Strg+Umschalt+Z | Rückgängig / Wiederholen (Quelltext, Grafik- und Song-Studios) |
| Cmd/Strg+F | Suchen … |
| Cmd/Strg+Alt+F | Ersetzen … |
| Cmd/Strg+L | Gehe zu Zeile … |
| Cmd/Strg+Umschalt+F | In Projekt suchen … (öffnet in der linken Spalte „Suche“) |
| F12 | Gehe zu Definition |
| F1 | Hilfe zum Wort unter dem Cursor |
| Cmd/Strg+I | Markdown: Kursiv |
| Cmd/Strg+E | Markdown: Code |
| Cmd/Strg+Umschalt+X | Markdown: Durchgestrichen |
| Cmd/Strg+Umschalt+K | Markdown: Link einfügen |

Vorschläge beim Tippen erscheinen von selbst (nach dem Tippen, nach „.“ und nach „@“); eine eigene Taste zum Öffnen gibt es nicht. **Fett** hat kein Kürzel: nimm den Befehl „Markdown: Fett“ in der Befehlspalette oder im Menü Bearbeiten. Auch „Markdown: Vorschau / Quelltext umschalten“ hat kein Kürzel.

## Ansicht und Oberfläche
| Taste | Wirkung |
|---|---|
| Cmd/Strg+K | Befehl oder Datei suchen … (Befehlspalette) |
| Cmd/Strg+B | linke Spalte ein- oder ausklappen |
| Cmd/Strg+J | Schublade ein- oder ausklappen |
| Cmd/Strg+Alt+B | rechtes Panel ein- oder ausklappen |
| Cmd/Strg+Umschalt+B | Zen-Modus: nur die Fläche, alles andere ausgeblendet (noch einmal: zurück) |
| Cmd/Strg+Umschalt+Enter | Bereich mit dem Fokus maximieren / wiederherstellen |
| Cmd/Strg+Alt+T | Editor teilen / Teilung aufheben |
| Cmd/Strg+Alt+→ / Cmd/Strg+Alt+← | nächster / vorheriger Reiter |
| Cmd/Strg+Plus (+) | Oberfläche vergrößern |
| Cmd/Strg+Minus (−) | Oberfläche verkleinern |
| Cmd/Strg+0 | Oberfläche: Originalgröße |
| Cmd/Strg+Komma (,) | Einstellungen |
| Menü-Taste oder Umschalt+F10 | Kontextmenü mit den Aktionen des Studios im aktiven Reiter |

Ohne Kürzel, aber im Menü **Ansicht**: Hell/Dunkel umschalten, Hoher Kontrast, Layout zurücksetzen, Editor-Schrift größer/kleiner, Darstellung zurücksetzen, Zeilenumbruch, die Befehle zum Maximieren einzelner Bereiche.

## Einzeltasten in den Studios
Sobald ein Studio den Fokus hat und kein Textfeld aktiv ist, gelten Einzeltasten (Buchstaben, Ziffern, Plus und Minus). Mit **Cmd**, **Strg** oder **Alt** gedrückt wirken sie nicht. Du schaltest sie unter Einstellungen ▸ Editor ab (**Einzeltasten der Studios**). Pfeile, Leertaste, Esc und Entf bleiben auch dann aktiv.

| Studio | Tasten |
|---|---|
| Sprites und Zeichensätze | D Stift, E Radierer, F Füllen, L Linie, R Rahmen, S Auswahl, I Pipette, X / Y spiegeln, 1 bis 4 Pixelwert, ← / → Frame, Entf oder Rücktaste leert die Auswahl, Esc hebt sie auf, + / − / 0 Zoom |
| Bildschirm | D Zeichen, T Text, F Füllen, R Rahmen, I Pipette, E Löschen, Pfeile bewegen den Cursor, + / − / 0 Zoom. Im Textwerkzeug tippst du Zeichen ein; Esc beendet es. |
| Kacheln | + / − / 0 Zoom |
| Bank-Studio | wie im Bildschirm-Editor, dazu L Linie, A Auswahl, S Stempel; Tab wechselt zwischen Kachel- und Zellenmodus; Leertaste setzt |

## Im Tracker
| Taste | Wirkung |
|---|---|
| Pfeile | Cursor im Muster bewegen (mit Umschalt: Auswahl) |
| Bild auf / Bild ab | 8 Zeilen hoch / runter |
| Pos1 / Ende | erste / letzte Zeile |
| Leertaste | Wiedergabe starten und anhalten |
| Umschalt+Leertaste | nur das gewählte Muster abspielen |
| Cmd/Strg+1 / Cmd/Strg+2 / Cmd/Strg+3 | Noten / Instrumente / Ablauf |
| Komma / Punkt | Oktave tiefer / höher |
| [ / ] | vorheriges / nächstes Instrument |
| Z S X D C V G B H N J M, Q 2 W 3 E R 5 T 6 Y 7 U I | Klaviertasten (zwei Oktaven; nach Tastenposition, auch auf deutschen Tastaturen) |
| 1 | Noten-Aus eintragen |
| Entf oder Rücktaste | Zelle leeren |
| Alt+↑ / Alt+↓ | Instrument der Zelle ändern |
| Cmd/Strg+C / X / V / A | Kopieren, Ausschneiden, Einfügen, Alles wählen |

Im Modus Instrumente wählen ↑ und ↓ das Instrument, die Klaviertasten und die Leertaste spielen es vor.

## Maus
| Aktion | Wirkung |
|---|---|
| Klick auf die Zeilennummer | Haltepunkt setzen oder löschen |
| Klick auf ▾ oder ▸ am Rand | Bereich falten oder entfalten |
