# Über VintageCoder

Die Seite **Über VintageCoder** zeigt Name und Versionsnummer, die Lizenz (GPL-3.0-or-later), Autor und Co-Autor, den Dank an die Community „N3rdroom“ (Discord), den Link zur Projektseite und die Drittanbieter-Hinweise (`THIRD-PARTY-NOTICES`).

Aufruf:

- Mac: Menü **VintageCoder → Über VintageCoder**
- Windows und Linux: Menü **Hilfe → Über VintageCoder**
- Befehlspalette (Strg/Cmd+P): „Über VintageCoder“

Der Link zur Projektseite öffnet sich nur auf Klick; die Seite ruft selbst nichts aus dem Netz ab.

Fehler und Wünsche meldest du über **Hilfe → Feedback senden …**, siehe [Feedback senden](help:feedback); die Seite hat dafür einen eigenen Knopf.
