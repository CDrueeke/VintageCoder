# Dateibaum: Marken und Farben

Jede Datei im Baum trägt vorn eine **Marke** aus drei bis vier Buchstaben. Die Farbe der Marke zeigt die Gruppe; sie ist nie das einzige Zeichen: die Marke steht immer als Text daneben.

| Marke | Gruppe | Farbe |
|---|---|---|
| ASM | Assembler-Quelltext | Akzent (blau) |
| BAS | BASIC-Quelltext | Grün |
| TRK, PLAY | Musik (Tracker, PLAY-Song) | Orange |
| SPR, CHR | Sprites, Zeichensätze | Blauviolett |
| SCR, MAP, PAL | Bildschirme, Kachelsätze, Paletten | Gelbbraun |
| NOT | Notizen (Markdown) | Textfarbe |
| (ohne Marke), TXT, BIN | Sonstige Dateien, Text, Binärdaten | Gedämpft |

Weitere Zeichen in der Zeile:

- **★** hinter dem Namen: das Startprogramm des Projekts.
- **●** hinter dem Namen: die Datei hat ungespeicherte Änderungen. Hinter einem eingeklappten Ordner: im Ordner liegt eine geöffnete Datei.
- **Kräftige Füllung mit Balken links**: die aktive Datei. **Leichte Füllung mit Punkt**: eine geöffnete Datei in einer anderen Gruppe.

Im Modus „Hoher Kontrast“ sind die Farben so gewählt, dass jede Marke gegen jede Fläche gut lesbar bleibt.
