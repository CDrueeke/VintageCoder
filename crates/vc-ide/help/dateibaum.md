# Dateibaum: Marken und Farben

Jede Datei im Baum trägt hinter dem Namen eine **Marke** aus drei bis vier Buchstaben. Sie zeigt die Gruppe der Datei und steht immer als Text da, nie nur als Farbe.

| Marke | Gruppe |
|---|---|
| ASM | Assembler-Quelltext |
| BAS | BASIC-Quelltext |
| TRK, PLAY | Musik (Tracker, PLAY-Song) |
| SPR, CHR | Sprites, Zeichensätze |
| SCR, MAP, PAL | Bildschirme, Kachelsätze, Paletten |
| NOT | Notizen (Markdown) |
| (ohne Marke), TXT, BIN | Sonstige Dateien, Text, Binärdaten |

Weitere Zeichen im Baum:

- **Diskette (Anwender):** Die Turbo-BASIC-XL-Diskette, die dir gehört, trägt diese Marke. Der Hinweis dazu: nicht einchecken, sie darf nicht jeder weitergeben.
- **Ordner** haben einen Pfeil zum Auf- und Zuklappen; die aufgeklappten Ordner merkt sich VintageCoder je Projekt.
- Die **gewählte Datei** ist hervorgehoben. Ein Punkt am Reiter im Dokumentenfeld zeigt ungespeicherte Änderungen.

## Bedienung
- **Klick** öffnet eine Datei; ein Diskettenabbild (`.d64`, `.d71`, `.d81`, `.atr`) öffnet im Disk-Editor.
- **Pfeiltasten** wechseln die Zeile, Rechts und Links klappen Ordner auf und zu, Enter öffnet. **F2** benennt um, **Entf** löscht (in den Papierkorb).
- **Rechtsklick** (oder die Menütaste) öffnet das Kontextmenü: Öffnen, Neue Datei, Neue Notiz, Neuer Ordner, Umbenennen, Löschen, Pfad kopieren, Im Ordner zeigen; auf freier Fläche außerdem Alle zuklappen, Neu einlesen und Verschieben rückgängig.
- **Ziehen** verschiebt eine Datei oder einen Ordner in einen anderen Ordner; die Pfade in den Quelltexten werden angepasst.
- Die Knöpfe über dem Baum: Dateien filtern, Neue Datei, Neuer Ordner, Projekt schließen.
